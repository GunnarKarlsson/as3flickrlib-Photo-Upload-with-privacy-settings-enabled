as3flickrlib Photo Upload with Privacy settings enabled
==============================================

Bug fix in as3flickrlib. Fixes a bug In the upload method in as3flickrlib to allow setting of privacy preferences when uploading images to a private account in Flickr.com.   Overview: as3flickrlib is an open source library which allows developers to interact with the Flickr.com API in ActionScript 3.0. When uploading an image to Flickr.com with as3flickrlib's Upload() method, all images are tagged as public by default, despite the method's privacy setting parameters having options for public, private and family. The reason is a bug in the string building for the service call.  The revised version allows the user to passed the desired privacy preferences for an image to Flickr.com, without altering the signature of the upload() method.  The as3flickrlib is available at http://code.google.com/p/as3flickrlib/. It appears the library issue tracking is no longer active.
